# 数据库 AI SQL 查询指南

用途：作为受控 Text-to-SQL 的通用生成上下文。

- 只使用随请求提供的授权 DDL 中真实存在的表、字段和关联关系。
- 完整保留用户问题中的过滤、排序、分组和聚合条件。
- 日期区间使用左闭右开的边界，避免遗漏包含时间成分的数据。
- 展示字符串字段的原值时可直接查询；对字符串字段进行数值统计时，只转换符合数值格式的值：

```sql
CASE WHEN TRIM(field) REGEXP '^[+-]?[0-9]+([.][0-9]+)?$'
     THEN CAST(field AS DECIMAL(12,4)) END
```

- 不得推测 DDL 中不存在的字段、关系、枚举含义或评价标准。
- 在 SQL 中完成必要的过滤、分组和聚合，避免返回大量无关原始记录。
