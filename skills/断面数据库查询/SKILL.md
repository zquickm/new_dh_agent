# 断面数据库查询

使用 `database_query` 查询断面历史观测数据。不要自行编写 SQL、猜测字段名或描述数据库结构；把用户的业务条件整理成完整、明确的自然语言问题交给工具。

## 路由边界

- E1、E2、E3 调查断面及其站位的复杂聚合、跨期统计和描述性评价，使用 `database_query`。
- 断面概况、最新快照、三个月内逐条明细、可用航次或专题出图，加载“断面观测与分析”，使用对应 `dm_duanmian_*` 工具，不重复用 SQL 查询相同结果。
- 仅查询断面测点分布、位置或空间属性时，加载“空间联动”并使用 `spatial_query`；不使用数据库观测记录代替空间目录，不把位置查询改成观测数据分析。
- 地图选区中的业务观测站，以及明确站名的状态、详情、最新观测、趋势或时间区间数据，使用 `observation_service`。
- 断面报告、制度和其他非结构化资料，使用 `rag_search`。
- 用户同时要求断面实测数据和报告依据时，按数据需求选择 `database_query` 或对应断面查询工具，并调用 `rag_search` 后综合回答。

## 断面与数据范围

- 东海共布设5条断面（E1、E2、E3、EL、EK）及4个辅助点，共34个站位。
- 主要的 E1、E2、E3 三条断面包含26个站位。库内这些站位同时有紧凑式和连字符式编码，例如 `E1001` 与 `E1-001`为同一站点不同时期的命名；去掉连字符后可归为 26 组：E1 的 001–007、E2 的 001–011、E3 的 001–008。每组两种存储形式对应不同内部 ID。用户倾向于使用`E1001`样式，除非明确要求精确存储编码，应在业务问题中统一使用`E1001`样式。
- 库内非 E1/E2/E3/EL/EK 站位编码包括 `A`、`B`、`C`、`D` 和 91 个纯数字历史编码；除非用户明确指定，否则不纳入断面查询。
- 海水化学观测指标为：海水温度、盐度、pH、溶解氧、活性磷酸盐、活性硅酸盐、亚硝酸盐、硝酸盐、氨氮、总碱度。
- 水文气象观测内容为：气温、风速、风向、气压、相对湿度、能见度、海况、波型、最大波高、波级、海发光类型、海发光强度、风浪、涌浪、有效波高、有效波周期、总云量、低云量、水色、透明度、水深。
- 基础信息为：观测日期、站位名称和编号、船舶名称和编号、经度、纬度；海水化学记录还包含采样层次。
- 当前数据画像中指标历史覆盖差异很大，pH 和营养盐字段尤其稀疏；请求统计时应同时获取各指标有效样本数，不用总记录数代替。

## 组织业务问题

传给 `database_query` 的 `question` 应完整保留用户指定的断面或站位、时间范围、采样深度、统计口径、排序、分组和明细要求；分批时仅缩小本批指标范围，全部批次合计必须覆盖用户要求的指标。

- 仅给出历史年月并询问“各类要素”或“全部要素”、没有指定对象时，按5条全部断面站位处理，不追问断面编号；回答时说明采用了该默认范围。
- 未要求“各站”或“逐站”时，按指定范围整体统计，不擅自拆成逐站结果。
- 用户只说“温度”且没有限定类型时，请求分别查询海水温度和气温，不要混合统计。
- 用户要求水质评价但没有提供评价标准时，采用断面数据库已有海水化学指标数据并做描述性分析；不要要求数据库工具判定水质等级或是否达标。
- 分析站位或垂向差异时，先查询总体汇总；只有用户要求或总体结果不足以回答时，再查询分组汇总，不默认拉取原始明细。
- 除上述默认口径外，存在会实质改变查询结果的歧义时，先请用户明确。

一般可省略 `limit`，使用工具默认上限；聚合结果可设置较小上限，用户要求明细时根据需要设置，但不得超过工具 Schema 的限制。

## 分批查询

用户询问各类要素或没指明要素时，在轮次充足时按表、要素组或时期拆批，保持条件和统计口径一致，但是最多也不要超过 4 批；仅剩 1～2 轮可查询时，尽量合并剩余需求并在当轮查齐。保留成功结果，仅补查缺项，最后统一汇总。

## 回答要求

- 数据库和知识库都返回数据时，优先采用数据库返回的数据回答，明确断面、时间范围、深度、指标、单位和统计口径。
- 先说明数据范围和有效样本覆盖，再给出主要统计、比较或描述性结论。
- `truncated=true` 时表明结果已截断，不得把返回部分当作完整数据；但除了只能最终回答不可避免时，不要直接告诉用户数据截断，可以说接下来继续查询剩余的某某数据。
- 空结果应如实说明并建议核对条件，不得自行放宽范围重新查询。
- 海水温度与气温必须分别表述；缺失值不得解释为 0。

## 能力边界

- 当前数据只有观测日期，没有观测时分秒。
- 当前不包含水质等级标准，也不包含湿球温度、绝对湿度、波速、明确波向、波长、声速或断面报告字段。
- 工具没有返回的数据不得推断或编造。
