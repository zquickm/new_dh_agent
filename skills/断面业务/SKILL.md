# 断面业务

断面一览统计使用 `spatial_query_service(operation="dm_duanmian_overview")`；最新观测、区间明细和航次列表分别使用同一工具的 `dm_duanmian_latest`、`dm_duanmian_observations`、`dm_duanmian_voyages`；空间位置与基础属性使用该工具的通用查询；接口未覆盖的历史观测、跨期指标统计和描述性分析使用 `database_query`，默认结合专题图出图；跨月全量化学要素对比使用 `dm_duanmian_element_compare`，其他专题图使用 `dm_duanmian_analysis`。各类问题按下述路由处理，并按“断面地图展示”同步展示用户指定对象，未指定对象时才展示三条断面，不要求每个问题调用全部工具。

## 路由边界

- “断面一览”“东海区断面情况概览”、断面数、测点数、监测要素清单及数量、数据总量、最近航次，先调用 `spatial_query_service(operation="dm_duanmian_overview")`，无其他参数。总体值直接使用 `overview`，单断面值使用 `sections`，要素清单使用 `chemistryElements/hydrometElements`；不从文档、固定数字、历史回答或数据库替代、去重或重算。失败或缺字段时说明未取得对应统计，不补零。仅此类统计不要求 RAG、数据库或专题出图；时间或选区筛选不可套用全区概览。
- 断面/测点最新观测快照使用 `spatial_query_service(operation="dm_duanmian_latest", code="E1")`；`code` 必填，可为断面前缀（如 E1/EK）或单测点（如 E1001），返回每站最近一次观测及各深度层。`elements` 使用接口原始物理列名，中文标签采用返回的 `chemistryFields/hydrometFields`，空值不能当作 0。
- 不超过 3 个月的逐条观测明细使用 `dm_duanmian_observations`，必填 `from/to`（yyyy-MM-dd，含起止日）；`code` 可省略，省略表示 E1/E2/E3 全部断面测点，响应为 `scope=all、code=null`，不能默认补成 E1。每次只返回一页，`page` 默认 1，`size` 默认 100、最多 1000；需要完整明细时按同一 code/from/to 继续翻页，不能把当前页 `rows` 当成 `total` 条完整数据或据此推算总体统计。无 code 命中超过 50000 条时如实说明服务错误并提示收窄时间或指定断面/测点，不截断、抽样或绕过限制。指定选区等接口不支持的筛选条件时，不省略这些条件改查全区。
- 可用航次使用 `spatial_query_service(operation="dm_duanmian_voyages", code="E1")`，`code` 必填，也支持单测点；`voyages` 按日期倒序，保留化学/水文覆盖测点数（0 表示该日该类型无观测）。专题出图需要确认可用航次时先查此接口，航次年月取返回 `date` 的前 7 位；某航次是否含目标要素有效值仍须由观测数据确认。
- 接口未覆盖的历史要素情况、分布、变化、对比和描述性分析，使用 `database_query` 查询数据，并按下文规则调用对应的出图工具，不能只返回文字或统计表。需要文档依据时再用 `rag_search`；同时按“断面地图展示”调用 `map_action`，向用户综合展示全面的信息。
  - 例：“2022年E1断面盐度情况”，先用 `database_query` 查询全年盐度统计及有有效盐度观测的航次，再用 `dm_duanmian_analysis` 出 `temp-section` 图，选择 `E1`、`盐度 S` 和结果中最新的实际航次，说明该图仅为全年中的单航次示例；地图仅展示 E1，统计与专题图仍仅针对 E1。

- 调查断面及其站位、辅助点的位置、基础属性和分布，使用 `spatial_query_service` 的通用查询；接口未覆盖的历史观测、跨期统计和描述性评价使用 `database_query`。空间记录不能代替历史观测数据，不为查询基础信息重复调用数据库。
- 通用查询通过 `spatial_query_service(operation=操作名, ...)` 调用；操作名是 `operation` 的枚举值，不能作为独立工具名。缺少目录结果时，先单独调用 `spatial_query_service(operation="list_spatial_elements")` 并等待返回，再选择目标类别并原样使用其 `dataKey`；已有目录结果可复用。默认字段满足需求时直接调用 `spatial_query_service(operation="query_spatial_element", query=查询条件)`，自选字段、过滤或排序前复用该类别字段定义，缺少时调用 `spatial_query_service(operation="get_spatial_element_detail", dataKey=类别标识)`。例如目录返回断面测点 `dataKey="dm_duanmian"`，则详情参数 `dataKey` 和查询参数 `query.element` 均用该值；`transect-stations` 仅为地图 `layer_id`，不得作为查询类别或据此推导类别。完整保留断面、站位及选区条件，不猜字段名或放宽为全库查询。
- 收到“要素/图层未注册”时重新查询目录；仅在目录能确定目标类别时，保留原条件修正一次。目录无目标类别或修正后仍失败时说明限制，不猜别名重试。
- 仅查询位置、基础属性或分布时不打开无关专题图；地图展示按下节执行。
- 仅要求专题出图或打开分析浮层时使用 `dm_duanmian_analysis`；跨月全量化学要素对比则使用 `dm_duanmian_element_compare`，由前端查询出图，无需额外查询数据库；仍须按下节同步展示对应范围的地图，浮层不能代替地图展示。
- 地图选区中的业务观测站，以及明确站名的状态、详情、最新观测、趋势或时间区间数据，使用 `spatial_query_service`。
- 断面业务信息、报告、制度和其他非结构化资料，使用 `rag_search`，必须使用标签：`断面`优先查询相关文档。
  按通用规则叠加时间标签，如 `["断面", "2021年", "3月"]`；逐年文档检索不受数据库最多4批的限制。
- 非结构化文档不能替代结构化查询结果：断面一览统计、位置与基础属性以 `spatial_query_service` 返回为准，接口未覆盖的历史观测和跨期指标分析以 `database_query` 返回为准，不用文档中的数值替代实际查询。

## 断面地图展示

- 询问断面信息（含一览、基础属性、历史要素、跨月对比、专题图和报告）时，默认同步展示地图，无需用户另说“展示地图”。范围优先按本轮明确对象，其次继承有效上下文：明确 E1 时仅展示 E1，明确 E1/E2 时仅展示 E1/E2，明确单测点时仅展示该测点；本轮和有效上下文均未指定对象时，才展示 E1、E2、E3。不得为了背景补画未指定断面，也不能用浮层默认 E1001 缩小未限定的范围。用户明确只要文字、只要表格、不要图或不要地图时不绘制。统计、文档检索和专题图仍保留原有断面、测点、时间及选区条件。
- 地图背景按上述对象范围单独查询真实几何，不套用业务查询的月份；明确测点时保留单站条件。沿用上节目录和字段发现流程，优先选择实际注册的断面线类别，设置 `query.includeGeometry=true`；类别和过滤字段必须以实际返回为准。只有测点类别时，查询指定断面的全部测点，指定单测点时只查该测点，如实展示点位，不按站号或返回顺序自行连线，不编造断面线或坐标。未指定对象时排除 EK、EL 及其他无关点位，明确指定 EK/EL 时保留用户范围。
- 从 `query.offset=0` 自动取齐匹配结果，优先一次查询覆盖本次指定范围。取得 `result_ref` 后调用 `map_action(action_type="GEOJSON_ADD", payload={"result_ref":查询返回的引用})`，保留原始几何和完整属性，图层由后端按类别补齐。分别查询时，同图层首次 `replace=true`，后续 `replace=false`，避免后一次查询覆盖此前结果。保留其他图层和有效选区；有选区时保持 `fit_bounds=false`，无选区时可设 `fit_bounds=true` 使视野覆盖本次对象。已有完整且仍有效、范围一致的展示无需重复绘制；从三条断面改问 E1 时应以 E1 结果替换原同类图层，历史 `result_ref` 不可复用。
- 地图查询、数据库、文档检索和出图中互不依赖的调用可同轮提交；地图查询失败、空结果或缺少几何不阻止文字分析与原出图工具。回答前确认已实际调用 `map_action` 或已有有效展示；未取全、缺少某条断面或只有测点时说明实际范围，不能把查询成功、部分几何或浮层回执当作三条断面已完整显示。

## 跨月要素对比

- 用户明确2–12个月份，询问“各类要素”“全部要素”或全量化学要素对比时，必须调用 `dm_duanmian_element_compare` 联动出图，无需用户另说“画图”；用户明确只要文字、只要表格或不要图时不出图。此规则优先于其他专题图规则，不用单航次图代替跨月对比，不为同一需求重复打开两种浮层。仅要求某个要素或水文气象图时仍按原专题图规则处理。
- `months` 必填，规范为 `yyyy-MM`，保留用户列出的月份顺序；用户明确变化基准时将基准月放首位，其余月份保留原顺序，不擅自排序或丢弃月份。缺少明确月份或超出12个月时说明工具限制，不编造参数。
- `station` 为 E1/E2/E3 前缀的5位测点编码，例 `E1-001` 规范为 `E1001`；优先用户或有效上下文中明确的测点，未指定时省略并使用默认 `E1001`，无需追问测点。该浮层只对比一个测点；默认测点图不能代表全断面或全部站位的统计范围，回答中说明本次浮层的测点。
- 浮层固定展示全量化学10项，同一测点同一月份取最后一次观测（航次），多层水深取表层。查询用于解释浮层的数据时必须保留此口径；用户未指定对象的整体统计仍按下文三条断面全部站位处理，不能被默认测点缩窄。
- 先加载 Skill；月份明确即可与数据库查询同轮提交，数据库失败、空结果或缺少坐标不阻止发送动作。需要文字比较结论时仍用 `database_query` 查询，回执不含观测值，不能据此推断变化或声称前端已出图。
- 例：“2022年11月与2021年11月各类要素对比情况” → `dm_duanmian_element_compare(months=["2022-11", "2021-11"])`，默认测点 `E1001`。

## 专题图参数

- **触发**：用户或有效上下文明确“E1/E2/E3 断面＋年月＋支持要素”并询问情况、分布、变化或分析时，必须调用 `dm_duanmian_analysis`，无需用户额外说“画图”。用户明确只要文字、只要表格或不要图时不出图；位置、基础属性、一览统计和文档查询不触发。不支持的断面或要素如实说明，不替换条件。
- **参数**：已知的 `analysis`、`section`、`voyage` 按图型传齐；`temp-section`、`surface` 还须传 `element`，`surface` 同时传对应 `elementType`。指定月份直接规范为 `yyyy-MM`（如 `2022-05`），不省略或改换航次。
- **图型**：海水化学分布默认用 `temp-section`；水文气象用 `surface`、`elementType="hydromet"`；明确要求化学要素表层沿程变化时用 `surface`、`elementType="chemistry"`。要素用 Schema 原值：水温 `温度 T`、盐度 `盐度 S`、pH `酸碱度 pH`、总碱度 `碱度 A`。只说“温度”时默认画海水温度并说明对象。明确要求溶解氧垂向、营养盐结构或 T-S 图时分别用 `do-profile`、`nutrient`、`ts-scatter`，省略 `element`；`ts-scatter` 合并全部断面，省略 `section`，不能替代单断面图。
- **年份或时间范围**：在同断面、同要素、同时间范围的查询结果中，选最新且该要素有有效观测的实际航次，说明仅为单航次示例；将航次与统计合并查询，不为出图额外查库。没有可靠航次时省略 `voyage`，仅打开浮层，不编造月份。
- **执行**：先加载 Skill；参数齐全即可与数据库查询同轮提交。数据库失败、空结果、缺少坐标均不阻止按指定条件出图，文档检索和标点也不是前置条件；仅航次依赖查询结果时等待返回。回答前确认本轮已实际调用，回执只代表指令已接收。
- 例：“2022年5月 E1 断面的温度情况” → `dm_duanmian_analysis(analysis="temp-section", section="E1", voyage="2022-05", element="温度 T")`。
- 例：“2022年5月 E3 断面的气温情况” → `dm_duanmian_analysis(analysis="surface", section="E3", voyage="2022-05", elementType="hydromet", element="气温")`。

## 断面与数据范围

- 当前东海共布设3条断面（E1、E2、E3）及4个辅助点，EK、EL断面不纳入此范围。
- E1、E2、E3 三条断面包含26个站位。库内这些站位同时有紧凑式和连字符式编码，例如 `E1001` 与 `E1-001`为同一站点不同时期的命名；去掉连字符后可归为 26 组：E1 的 001–007、E2 的 001–011、E3 的 001–008。每组两种存储形式对应不同内部 ID。用户倾向于使用`E1001`样式，除非明确要求精确存储编码，应在业务问题中统一使用`E1001`样式。
- 库内非 E1/E2/E3/EL/EK 站位编码包括 `A`、`B`、`C`、`D` 四个辅助点和 91 个纯数字历史编码站点。
- 上述数量及编码分组仅作业务背景；一览统计以本轮 `dm_duanmian_overview` 接口返回为准，不根据本说明重算或覆盖接口统计。
- 海水化学观测指标为：海水温度、盐度、pH、溶解氧、活性磷酸盐、活性硅酸盐、亚硝酸盐、硝酸盐、氨氮、总碱度。
- 水文气象观测内容为：气温、风速、风向、气压、相对湿度、能见度、海况、波型、最大波高、最大波周期、波级、海发光类型、海发光强度、风浪、涌浪、有效波高、有效波周期、总云量、低云量、低云高、云状、天气现象、水色、透明度、水深。
- 基础信息为：观测日期、站位名称和编号、船舶名称和编号、经度、纬度；海水化学记录还包含采样层次。
- 当前数据画像中指标历史覆盖差异很大，pH 和营养盐字段尤其稀疏；请求统计时应同时获取各指标有效样本数，不用总记录数代替。
- 关于断面通报，位于知识库中，每年有四份，分别是2、5、8、11月份

## 组织业务问题

查询数据库时，不要自行编写 SQL、猜测字段名或描述数据库结构；把用户的业务条件整理成完整、明确的自然语言问题。传给 `database_query` 的 `question` 应完整保留用户指定的断面或站位、时间范围、采样深度、统计口径、排序、分组和明细要求；全部批次合计必须覆盖用户要求的指标。

- 仅给出历史年月并询问“各类要素”或“全部要素”、没有指定对象时，按三条断面的全部站位处理，不追问断面编号。
- 未要求“各站”或“逐站”时，按指定范围整体统计，不擅自拆成逐站结果。
- 用户只说“温度”且没有限定类型时，请求分别查询海水温度和气温，不要混合统计。
- 用户要求水质评价但没有提供评价标准时，采用断面数据库已有海水化学指标数据并做描述性分析；不要要求数据库工具判定水质等级或是否达标。
- 除上述默认口径外，存在会实质改变查询结果的歧义时，先请用户明确。
- 除非用户明确要求逐行明细，所有查询都必须严格控制结果行数。
- 不得通过只取前若干行代替完整范围统计。

## 分批查询

用户询问各类要素或没指明要素时，在轮次充足时按表、要素组或时期拆批，保持条件和统计口径一致，但是最多也不要超过 4 批；仅剩 1～2 轮可查询时，尽量合并剩余需求并在当轮查齐。保留成功结果，仅补查缺项，最后统一汇总。

## 回答要求

- 数据分析先说明数据范围和有效样本覆盖，再给出主要统计、比较或描述性结论；专题出图只说明工具回执确认的动作。
- `truncated=true` 时表明结果截断，必需在之后补全截断数据，但绝对不能告诉用户数据截断。
- 空结果应如实说明并建议核对条件，不得自行放宽范围重新查询。
- 海水温度与气温必须分别表述；缺失值不得解释为 0。

## 能力边界

- 当前数据只有观测日期，没有观测时分秒，此限制针对断面数据库。
- 断面数据库当前不包含水质等级标准，也不包含湿球温度、绝对湿度、波速、明确波向、波长、声速或断面报告字段。
- 专题出图支持的断面、分析类型及参数以 `dm_duanmian_analysis` Schema 为准，用户明确查询 EL、EK 等对象时也不得向出图工具传入不支持的值。
- 工具没有返回的数据不得推断或编造。
