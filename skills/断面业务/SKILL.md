# 断面业务

断面的空间位置与基础属性使用通用空间查询；历史观测、统计和描述性分析使用 `database_query`；专题图使用 `dm_duanmian_analysis`。按问题组合数据、地图和专题图，不要求每个问题调用全部工具。

## 查询与展示流程

本 Skill 独立指导断面查询、分析和展示，直接复用所需工具。先通过 `load_skill(name="断面业务")` 取得本说明，再调用断面业务工具；当前上下文已有本说明时无需重复加载。

- 位置、数量、基础属性、区域内断面及测点分布：直接使用 `spatial_query_service` 的通用查询。先用 `list_spatial_elements` 发现断面类别（如 `dm_duanmian`），需要字段过滤时用 `get_spatial_element_detail` 获取定义，再用 `query_spatial_element` 查询记录。使用真实返回的字段，不猜测字段名。选区查询传 `query={"element": dataKey, "mode": "spatial", "spatial": selected_area.spatial}`，完整保留范围；需要地图展示时请求返回几何，并在查询成功后调用 `map_action`。根据实际结果回答，无需转入另一业务流程。
- 断面指标、历史观测、变化、比较、水质描述或其他数据分析：使用 `database_query` 查询实际数据，并默认调用 `dm_duanmian_analysis` 展示相关专题图，无需用户另说“出图”。用户明确只要文字或不需要图时遵循用户要求。
- 仅要求打开专题图时，加载本 Skill 后调用 `dm_duanmian_analysis`；不为出图额外查询数据库。专题图回执不能作为实测值或分析结论的来源。
- 分析时需要展示目标站位，可复用已有真实点位用 `map_action` 展示，或先用通用空间查询获取几何再调用 `map_action`；已有对应地图结果时不重复绘制。
- 断面报告、制度、背景等非结构化资料使用 `rag_search`，传 `tags=["断面"]`。用户同时需要文档依据和实测分析时分别检索文档、查询数据库后综合回答；实测数值和统计结论以数据库结果为准。
- 本 Skill 处理调查断面及其测点，不将其他业务观测站的同名指标误查为断面数据。

## 专题分析图

- 根据用户问题选择相关图型，不要求用户先说出工具的分析类型。盐度、海水温度及其他化学指标的断面分布用 `temp-section`；温盐水团关系用 `ts-scatter`；营养盐关系用 `nutrient`；溶解氧垂向变化用 `do-profile`；单站指标随水深变化用 `depth-curve`；表层沿程变化用 `surface`。
- 综合断面数据分析未指定图型时，默认以 `temp-section` 展示海水温度；明确说出指标时优先展示该指标。仅查询位置、数量、基础属性或文档资料时不打开无关专题图。区域总览发现断面时只输出查询结果和地图分布。
- `analysis` 必填，其余参数按 Schema 传入；可确定的断面和指标直接填写，不支持的断面或指标不替换成其他对象。图型无法覆盖用户问题时说明展示范围，不把一张图当作全部分析。
- 航次通常为2月、5月、8月、11月。保留用户明确指定的航次；仅指定年份或时间范围时，可选择数据库结果中该范围内最新的实际航次作为示例，并明确说明图展示的航次，文字统计仍覆盖用户要求的完整范围。不随机选择或编造航次；没有可靠航次时省略 `voyage` 打开浮层供选择。
- 例：“2022年E1断面盐度情况”先查询2022年E1盐度及实际航次，再调用 `dm_duanmian_analysis(analysis="temp-section", section="E1", element="盐度 S", voyage=查询结果中2022年最新航次)`；缺少可靠航次时省略 `voyage`。
- 成功回执只表示指令已发送；没有前端渲染确认时不声称图已显示，也不把当前浮层默认值当成查询结果。

## 测点地图展示

- 位置、数量和分布查询取得结果后调用 `map_action` 展示，查询工具不会绘图。需要几何时设置 `includeGeometry=true`；明确选区必须使用完整 `selected_area.spatial`，不以全库属性查询替代。对象以本轮明确需求为准，不从历史恢复失效选区；缺少必要范围或存在无法消除的对象歧义时请用户明确。
- 通用查询按页返回数据，需要完整展示时保持条件补取后续页，再合并真实点位提交；未取全时说明覆盖范围，不把第一页当作全部。点位用 `MARKER_ADD`，真实线面用 `GEOJSON_ADD`；沿用稳定图层，避免重复覆盖。
- 用户查询某个历史航次的实际测点位置时，由 `database_query` 保留航次、站位和空间条件查询真实坐标，再用 `map_action(MARKER_ADD)` 展示。若数据库无法准确满足空间范围，说明限制，不放宽范围。
- 展示数据库点位前按站位去重，保留真实标识、名称和经纬度，不因多日期、多深度的观测行重复标点；同站位有多个位置时保留用户指定的时间口径，不任取坐标。
- 数据库点位使用独立图层 `transect-stations`；替换结果只清除该图层，不取消选区。一次提交 `markers`，每项含 `id`、`name`、`coordinates=[经度, 纬度]`，顶层 payload 含 `layer_id="transect-stations"`；有有效选区时 `fit_bounds=false`。
- 数据库点位需要替换时先调用 `map_action(action_type="CLEAR", payload={"layer_ids":["transect-stations"]})`，不设置 `clear_selection=true`。
- 无匹配结果只清除对应图层；查询失败时保留已有结果。缺失坐标的记录不绘制，说明可绘制数量。只有真实线面几何才使用 `GEOJSON_ADD`，不自行将测点连成断面线。

## 断面与数据范围

- 当前东海共布设5条断面（E1、E2、E3、EL、EK）及4个辅助点。
- 主要的 E1、E2、E3 三条断面包含26个站位。库内这些站位同时有紧凑式和连字符式编码，例如 `E1001` 与 `E1-001`为同一站点不同时期的命名；去掉连字符后可归为 26 组：E1 的 001–007、E2 的 001–011、E3 的 001–008。每组两种存储形式对应不同内部 ID。用户倾向于使用`E1001`样式，除非明确要求精确存储编码，应在业务问题中统一使用`E1001`样式。
- 库内非 E1/E2/E3/EL/EK 站位编码包括 `A`、`B`、`C`、`D` 四个辅助点和 91 个纯数字历史编码站点。
- 海水化学观测指标为：海水温度、盐度、pH、溶解氧、活性磷酸盐、活性硅酸盐、亚硝酸盐、硝酸盐、氨氮、总碱度。
- 水文气象观测内容为：气温、风速、风向、气压、相对湿度、能见度、海况、波型、最大波高、最大波周期、波级、海发光类型、海发光强度、风浪、涌浪、有效波高、有效波周期、总云量、低云量、低云高、云状、天气现象、水色、透明度、水深。
- 基础信息为：观测日期、站位名称和编号、船舶名称和编号、经度、纬度；海水化学记录还包含采样层次。
- 当前数据画像中指标历史覆盖差异很大，pH 和营养盐字段尤其稀疏；请求统计时应同时获取各指标有效样本数，不用总记录数代替。

## 组织业务问题

查询数据库时，不要自行编写 SQL、猜测字段名或描述数据库结构；把用户的业务条件整理成完整、明确的自然语言问题。传给 `database_query` 的 `question` 应完整保留用户指定的断面或站位、时间范围、采样深度、统计口径、排序、分组和明细要求；全部批次合计必须覆盖用户要求的指标。

- 仅给出历史年月并询问“各类要素”或“全部要素”、没有指定对象时，按5条全部断面站位处理，不追问断面编号。
- 未要求“各站”或“逐站”时，按指定范围整体统计，不擅自拆成逐站结果。
- 用户只说“温度”且没有限定类型时，请求分别查询海水温度和气温，不要混合统计。
- 用户要求水质评价但没有提供评价标准时，采用断面数据库已有海水化学指标数据并做描述性分析；不要要求数据库工具判定水质等级或是否达标。
- 除上述默认口径外，存在会实质改变查询结果的歧义时，先请用户明确。
- 除非用户明确要求逐行明细，所有查询都必须严格控制结果行数
- 不得通过只取前若干行代替完整范围统计。

## 分批查询

用户询问各类要素或没指明要素时，在轮次充足时按表、要素组或时期拆批，保持条件和统计口径一致，但是最多也不要超过 4 批；仅剩 1～2 轮可查询时，尽量合并剩余需求并在当轮查齐。保留成功结果，仅补查缺项，最后统一汇总。

## 回答要求

- 数据分析先说明数据范围和有效样本覆盖，再给出主要统计、比较或描述性结论；专题出图只说明工具回执确认的动作。
- `truncated=true` 时按原条件补全所需数据；未补齐时说明结果范围，不把部分数据称为全部。
- 空结果应如实说明并建议核对条件，不得自行放宽范围重新查询。
- 海水温度与气温必须分别表述；缺失值不得解释为 0。

## 能力边界

- 当前数据只有观测日期，没有观测时分秒，此限制针对断面数据库。
- 断面数据库当前不包含水质等级标准，也不包含湿球温度、绝对湿度、波速、明确波向、波长、声速或断面报告字段。
- 专题出图支持的断面、分析类型及参数以 `dm_duanmian_analysis` Schema 为准，不因本 Skill 涵盖 EL、EK 等对象就向出图工具传入不支持的值。
- 工具没有返回的数据不得推断或编造。
