# 断面观测与分析

## 选择工具

| 需求 | 工具 |
| --- | --- |
| 断面一览、断面/测点/指标数、记录总量、最近观测日期 | `dm_duanmian_overview`，无入参，口径固定 E1/E2/E3 |
| 某断面或测点各站最新观测 | `dm_duanmian_latest(code)` |
| 三个月内指定日期范围的逐条明细 | `dm_duanmian_observations(code, from, to, page, size)` |
| 某断面或测点可用航次 | `dm_duanmian_voyages(code)` |
| 打开断面专题面板或请求自动出图 | `dm_duanmian_analysis` |
| 跨期比较、均值、分组统计、排名、超过三个月的分析 | 加载“断面数据库查询”，使用 `database_query` |
| 断面测点分布、位置、空间属性 | 加载“空间联动”，使用 `spatial_query` |
| 报告、制度和文档依据 | `rag_search`；同时需要实测数据时再调用相应业务查询工具 |

业务观测站的状态、最新值和趋势继续使用 `observation_service`，不能把断面编号当作观测站 tzno。

## 查询规则

- code 两位时表示断面前缀，其他长度表示完整测点标识；支持 E1/E2/E3、EK/EL 等服务可查询对象。只做大小写归一化，不删除已有编码中的连字符。E1001 与 E1-001 的历史覆盖依赖上游，查询一个编码不代表另一个编码的数据已包含。
- 缺少必要对象或日期时先从当前用户请求、有效历史继承，仍不明确再追问；不得编造参数。相对日期需要可靠当前时间时使用 CurrentServerTime。
- overview 的 E1/E2/E3 总数不能说成包括 EK/EL 的全部断面；dataCount 是观测记录量，不是有效指标值数量。
- latest 是逐站最新快照，各站和化学/水文日期可能不同。保留各行 observedAt，不能说成实时值，也不能拼成同一航次剖面。
- observations 的 from/to 使用 yyyy-MM-dd，包含边界，后端按三个自然月上限校验；默认每页 100、最多 1000。上游如果有更严格的日期约束，应如实报告，不能自动缩短范围。
- `total` 为匹配记录数，`returned` 为本页行数。`partial=true` 时不得对本页做全量统计，`has_more=true` 才表示当前页后仍有数据。用户要统计时在数据库内聚合，不默认遍历全部明细。
- 日期、字段标签、单位使用响应中的 observedAt、chemistryFields、hydrometFields，elements 的键是物理列名。空值保持缺测，不能填零；不推测未返回的字段和单位。
- 化学 depthM 是采样层次；水文 depthM 是站点水深，可能含空串或“＞1000”，不能当作相同采样层关联两表。水温与气温分别表述。
- 查询失败与空结果不同，失败不报“查无数据”、不自动切换数据源或放宽条件。接口没有空间坐标时不额外编造标点。

## 分析面板

工具只发送展示指令，实际取数、图形计算和渲染由前端完成。不要在回答正文输出 JSON/map_actions，也不要再调用 map_action 重复请求面板。

1. 用户只要求打开面板：传 analysis，可带明确的其他参数，省略 voyage；不得主动补一个航次。不传 voyage 不自动查询。
2. 用户要求出图：明确 analysis、航次，以及该图需要的断面和指标。用户说“最新航次”时先查 voyages，选有对应数据类型覆盖的真实观测日；不使用 overview 的全局最新日或 latest 的逐站日期代替。
3. voyage 可传 yyyy-MM 或 yyyy-MM-dd。后端出图前复核：该月只有一个观测日时可传月；有多个观测日时须明确选择日期，不能自行合并或取第一个。不能自动改成其他月份。
4. 出图断面仅 E1/E2/E3；EK/EL 可以查询，但不能在此面板出图。
5. 返回 `auto_query_requested=true` 仅表示已请求前端取数出图，不是渲染回执，也不保证目标指标非空。前端仍需检查有效值、采样层和实际覆盖。

| analysis | 参数与范围 |
| --- | --- |
| depth-curve | 单要素沿深度变化；自动出图需 section、voyage、element |
| temp-section | 化学要素断面插值图；自动出图需 section、voyage、element，固定 chemistry |
| ts-scatter | 温盐散点，固定合并 E1/E2/E3，不传 section/element；指定单断面的请求当前不支持，不能静默扩大。自动出图核对三条断面的共同观测日及化学覆盖 |
| nutrient | 营养盐多要素分析，chemistry，不传单一 element；自动出图需 section、voyage |
| do-profile | 溶解氧垂向分析，chemistry，element 固定 dissolved_oxygen_umol_dm3；自动出图需 section、voyage |
| surface | 单要素表层沿程；自动出图需 section、voyage、element |

elementType 使用伙伴字段名，省略默认 chemistry；depth-curve/surface 可指定 hydromet，但水文水深不代表逐层采样，不能把它解释为水体垂向实测剖面。自动出图时，后端从最新观测接口的字段清单确认单指标的物理列名；该调用仅用于字段发现，不把其中最新值当成绘图航次的数据。优先传工具返回的物理列名或完整标签；“温度/水温”默认映射海水温度，需要气温时明确指定。

## 解释图表

- 用户要求“出图并分析”时，必须另查相同断面、日期、指标和采样层口径的数据。不能仅凭展示指令成功给出数值、趋势或结论。
- 插值色阶不是所有位置的实测值；保留缺测和异常值语义。温盐散点不能自动判定水团归属，溶解氧图不能自动判定缺氧等级，营养盐缺测不能补出完整比例关系。
- 当前后端没有面板手动切换状态或渲染回执。用户手动更改图后询问“这张图”，需确认实际参数；不声称已读取页面图像。
